# prime-numbers-interval-java
Java program to count prime numbers in an interval
This project contains a Java program that calculates how many prime numbers exist between two given integers.

## How it works
- The program asks the user to enter two integers between 2 and 20000.
- It validates the input values.
- It checks each number in the interval to determine if it is prime.
- Finally, it prints the total count of prime numbers found.

## Example
Input:
10 20
Output:
4

## Usage
1. Compile the program:
javac PrimeNumbersInInterval.java
2. Run the program:
java PrimeNumbersInInterval
3. Enter two integers when prompted.
